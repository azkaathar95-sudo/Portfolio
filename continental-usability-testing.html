Problem

The existing onboarding process was reported to be unintuitive and error-prone, especially for new users. The goal was to validate whether a redesigned version could improve usability, reduce errors, and better align with real-world workflows.

Unintuitive Error-prone Poor workflow alignment
Hypothesis

The redesigned onboarding interface will be more intuitive, reduce cognitive load, and improve task efficiency across all user types — from beginners to experts.

More intuitive Reduced cognitive load Better efficiency

Research Tasks

Task 1 · Web Portal Usability Testing

Scenario: Vehicle profile creation in an office setting using the web portal.

Method: Think-aloud protocol with both current and redesigned versions.
Outcome: All participants preferred the new version due to improved clarity and reduced error potential.
Task 2 · Mobile Prototype Walkthrough

Scenario: Vehicle creation in a workshop environment using the mobile application.

Method: Cognitive walkthrough using a Figma prototype.
Outcome: Participants appreciated the process efficiency but noted areas for improvement in navigation, and external constraints such as severe outdoor weather and internet connectivity.
Task 3 · New Scan Device Integration

Scenario: Introduction to a new scanning device in a workshop environment.

Method: Interactive prototype demonstration and feedback collection.
Outcome: Users saw potential for improving efficiency but requested clearer guidance — especially for experienced users with learned behavior, plus better error handling and accounting for external factors.

Methodology & Analysis

Approaches Considered
  • •Lab-based usability testing in a controlled environment
  • •Pre-task interviews and post-task feedback sessions
  • •Figma prototypes for unbuilt features
  • •Think-aloud protocol for developed prototypes
  • •Cognitive walkthrough for Figma prototypes
Advantages
  • ✓Controlled environment reduced external variables
  • ✓Think-aloud provided deep insight into user thought processes
  • ✓Figma prototypes enabled early feedback before development
Limitations
  • •Lab setting may have created pressure for novice users
  • •Limited interactivity in Figma prototypes restricted full exploration
  • •Small sample size may not represent all user types and requirements
